# Лабораторная работа № 8. Хранение данных и настройки.

&nbsp;&nbsp;&nbsp;&nbsp;До этого момента мы сохраняли данные приложения только на время его нахождения в памяти. Однако, в реальности приложения должны сохранять данные и между запусками — будь то последний пройденный уровень викторины, выбранный цвет экрана или список дел на будущую неделю. Для этих целей используются разные походы, от сохранения настроек до баз данных. В данной лабораторной работе мы будем иметь дело с настройками и файловыми операциями.
